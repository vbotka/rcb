RCB (Rsync-Crypto-Backup)
=========================

version |release|

This is an open-source `BSD-2-clause license`_ light-weight remote `incremental backup`_ using `rsnapshot`_, `rsyncrypto`_, and `rsync`_.

Feel free to `share your feedback and report issues`_.

`Contributions are welcome <https://github.com/firstcontributions/first-contributions>`_.

source: https://github.com/vbotka/rcb
